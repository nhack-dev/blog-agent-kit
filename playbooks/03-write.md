# 03 本文を書く

## ゴール
`drafts/<slug>.md` に、前置き（front matter）つきの本文がある。

## 前置きの書き方

```
---
title: 記事のタイトル
slug: url-ni-naru-eigo
excerpt: 検索結果やSNSで出る説明文（80〜120字）
category_ids: [3]      # wp_check.py --go で出た ID
tag_ids: [10, 12]
affiliate: false       # 広告リンクを含むなら true
---
```

## 書き方の決まり
- **冒頭で結論。** 最初の3行で「答え」と「この記事で分かること」を書く。
- 1文は60字前後。長くなったら2つに切る。
- 1段落は3〜4文まで。スマホで読む前提。
- 専門用語は初めて出たときに一言で説明する。
- 数字・制度・料金は出どころのリンクを横に置き、確かめた日を書く（例：「2026年10月時点・公式サイトより」）。
- 手順は番号つきの箇条書き。1つの番号に1つの動作。
- 表は比べるときだけ使う（スマホでは横に長い表は読みにくいので3列まで）。
- 画像は自分で作る・撮る・利用条件を確かめた素材だけ。`![説明](images/xxx.png)` と書けば `wp_draft.py --upload-images` で送れる。
- **体験の段落**は `【体験：オーナーに聞く】` と書いて空けておく。作らない。
