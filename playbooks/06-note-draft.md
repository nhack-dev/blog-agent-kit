# 06 note 用の下書き

note には一般に公開された投稿用 API がありません。**自動では投稿しません。** 貼り付け用のファイルを作り、オーナーが貼ります。

## 手順
1. ブログ用の記事をそのまま使うか、note 向けに書き直す（note は「読み物」寄り。見出しを減らし、語りかける文にすると読まれやすい）。
2. `python3 scripts/note_draft.py drafts/<slug>.md`
3. `out/note/<slug>.txt` を開き、note の新規作成画面に貼る。
   - 本文中の `［画像1を差し込む：…］` の所に、`out/note/<slug>-images.txt` の画像を入れる。
   - 見出しは note のエディタで「大見出し」「小見出し」を選び直す。
4. note の画面で「下書き保存」。公開はオーナーが決める。

## 注意
- 同じ文章をブログと note に両方出すと、検索ではどちらか一方しか出ないことが多い。どちらを主にするかオーナーと決める（片方は要約＋リンクにする等）。
- 広告を含むなら冒頭に表示を入れる（道具が自動で1行足します）。
