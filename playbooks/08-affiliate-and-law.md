# 08 アフィリエイト記事と法律の注意

この手順書は法律の助言ではありません。迷うもの・大きなお金が動くもの・健康や美容の商品は、専門家や広告主・ASP（アフィリエイトの仲介会社）の規定で確かめてください。法律や運用は変わるので、**書く前に官公庁の最新のページを確かめる**こと。

## 1. ステルスマーケティング規制（2023年10月1日から）
- 景品表示法の告示で、「事業者の広告なのに、一般消費者が広告だと分からない表示」が不当表示になりました。所管は消費者庁。
- 規制の対象は**広告主（事業者）**です。ただし広告主はアフィリエイトサイトにも表示を求めるので、ASP・広告主の規約で必須になっていることがほとんどです。
- 書くこと：記事の**冒頭**に、はっきり分かる大きさ・色で「広告」「PR」「プロモーションを含みます」などを入れる。
  - 末尾だけ・小さい文字・背景に溶ける色は不十分とされます。
  - 「〇〇社から商品の提供を受けて書いています」のように、事業者の表示だと分かる書き方も可。
- 消費者庁「ステルスマーケティングに関する景品表示法の考え方」：https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/

## 2. 景品表示法（優良誤認・有利誤認）
- **優良誤認**：実際より、または他社より著しく良いと思わせる表示。「No.1」「最高品質」「業界初」は、根拠（誰が・いつ・どの範囲で調べたか）が無ければ使わない。根拠があっても、記事に根拠を書く。
- **有利誤認**：実際より得だと思わせる表示。「今だけ」「通常価格〇〇円が半額」は、本当に期間が限られ、比べる価格に実績があるときだけ。
- 架空の口コミ・作った体験談・自作自演のランキングは書かない。
- 消費者庁 景品表示法：https://www.caa.go.jp/policies/policy/representation/fair_labeling/

## 3. 医薬品医療機器等法（薬機法）
- 医薬品でない商品（健康食品・サプリ・一般の化粧品・雑貨）に、病気が治る・予防できる・体の機能が変わる、と書かない。
  - 例：「飲むだけで痩せる」「シミが消える」「免疫力が上がる」「育毛」「デトックス」
- 化粧品は、認められた効能の範囲の言い方（「肌にうるおいを与える」など）にとどめる。
- 「医師も推奨」「臨床で証明」などは、広告主から根拠と使用許可が出ている場合だけ・言い回しは広告主の指定どおりに。
- 体験談でも、効き目を保証する書き方はできない。
- 厚生労働省 医薬品等の広告規制：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/koukokukisei/index.html

## 4. お金・副業・投資の記事
- 「誰でも稼げる」「必ず儲かる」「月〇万円確実」は書かない（収入の保証と受け取られる）。
- 実績を書くなら、オーナー本人の数字だけ・期間と条件つき・「同じ結果を約束するものではありません」。
- 投資商品を勧める記事は、金融商品取引法など別の決まりがかかることがあります。オーナーと専門家に確かめる。

## 5. ASP・広告主の規約
- 広告主ごとに「使ってはいけない言葉」「指名キーワードでの広告の禁止」「価格の書き方」などの決まりがある。**提携の画面にある規定を記事を書く前に読む。**
- 商標名をタイトルに入れてよいか、画像を使ってよいかも規定で確かめる。

## アフィリエイト記事の書き方（型は templates/ の比較・レビュー）
1. 冒頭に広告の表示 → 結論（誰に何が向くか）
2. 選び方の基準を先に出す（読み手が自分で決められるように）
3. 比べる表は同じ基準・同じ日付で。値段は確かめた日を書く
4. 良い点だけでなく、合わない人・弱い点を書く（信頼が上がり、誤認も避けられる）
5. オーナーの体験は事実だけ。使っていない商品は「使っていない」と書く
6. 最後に「公式サイトで最新の条件を確かめてください」

## 最後の確認（全部「はい」で下書きへ）
- [ ] 冒頭に広告の表示があり、はっきり読める
- [ ] 「No.1」「最安」「初」などに根拠が書いてある（または使っていない）
- [ ] 効き目・効能の言い方が商品の種類の範囲に収まっている
- [ ] 収入・効果を保証する言い方が無い
- [ ] 口コミ・体験はすべて本物で、オーナーのものか、出どころと許可がある
- [ ] 価格・条件に確かめた日がある
- [ ] 広告主・ASP の規定を読んだ
- [ ] `review_check.py --strict` が終了コード0
