# blog-agent-kit：AIエージェントがブログ記事を書き続けるためのキット

あなたの AIエージェント（Claude Code など）にこのフォルダを読ませると、次の仕事を手順どおりに進めます。

1. **キーワード調査** … 検索する人が何を知りたいのか（検索意図）を決め、上位記事の見出しを比べる
2. **構成** … 見出しの並びと、各見出しで答えることを決める
3. **本文** … 型に沿って書く。あなた自身の体験を入れる場所も作る
4. **推敲** … 事実の確認・読みやすさ・法律上の注意（誇大表現・薬機法・景品表示法・ステマ規制）
5. **WordPress に下書き投稿** … あなたのサイトに「下書き」で入れる（公開は、あなたが画面で押す）
6. **公開後の振り返り** … Search Console の数字で、伸びしろの語・タイトルの直し候補を出す（任意）
7. **note 用の下書き** … note に貼りやすい形のファイルを作る（note への投稿は手で行う）

アフィリエイト記事（比較・レビュー・ランキング）の型も入っています。

## 費用

- このキット自体に月額費用はありません。こちらのサーバーや鍵は一切使いません。
- かかるのは、**あなたが使う AIエージェントの利用料**と、あなたのサイトのサーバー代だけです。
- WordPress の REST API・Search Console API は、ふつうの使い方なら無料で使えます。

## 最初の10分

用意するもの：Python 3.11 以上、あなたの WordPress サイト（https のもの）、AIエージェント。

```bash
# 1. このフォルダに移動して、設定ファイルを作る（2分）
cp .env.example .env

# 2. WordPress の「アプリケーションパスワード」を作って .env に書く（5分・下の手順）

# 3. つながるか確かめる（1分）
python3 scripts/wp_check.py          # 試し：何も送りません
python3 scripts/wp_check.py --go     # 実際に読みに行き、カテゴリとタグの ID を出します

# 4. 見本の記事を下書きで入れてみる（2分）
python3 scripts/review_check.py examples/sample-article.md
python3 scripts/wp_draft.py examples/sample-article.md          # 試し
python3 scripts/wp_draft.py examples/sample-article.md --go     # 下書きとして入る
```

WordPress の管理画面 → 投稿 → 下書き に見本が入っていれば準備完了です。見本は確認後に削除してください。

その後は AIエージェントに、たとえば次のように頼みます。

> 「AGENT.md を読んで、『在宅ワーク 始め方』で1本書いて。WordPress に下書きまで入れて」

## 必要なキーの取り方

### WordPress のアプリケーションパスワード（必須）

1. WordPress の管理画面にログイン
2. 「ユーザー」→「プロフィール」を開く
3. 下の方の「アプリケーションパスワード」で名前（例：`blog-agent`）を入れて「新しいアプリケーションパスワードを追加」
4. 出てきた24文字を `.env` の `WP_APP_PASSWORD` に貼る（画面を閉じると二度と見られません）

- WordPress 5.6 以上の機能です。**https のサイトでだけ**既定で使えます。
- 欄が無いときは、セキュリティ系のプラグインで止められていることがあります。プラグインの設定を確かめてください。
- 権限は「編集者」以上のユーザーで作ってください（「投稿者」だと他の人の下書きを直せません）。
- 不要になったら同じ画面で「取り消し」を押せば、すぐ使えなくなります。

### Search Console（任意・振り返りに使う）

手順は [playbooks/07-after-publish.md](playbooks/07-after-publish.md) にあります。Google Cloud で無料の「OAuth クライアント ID」を作り、`python3 scripts/gsc_auth.py --go` で鍵を取ります。

## 中身

| 置き場 | 中身 |
|---|---|
| `AGENT.md` | AIエージェントへの指示書（役割・毎回の流れ・判断の基準・やってはいけないこと） |
| `CLAUDE.md` | Claude Code に AGENT.md を読ませる1行 |
| `playbooks/` | 作業ごとの手順（01 キーワード 〜 08 アフィリエイトと法律） |
| `templates/` | 記事の型・構成の型・調査シート・推敲チェック表 |
| `scripts/` | 補助の道具（どれも「試し」が既定。送るのは `--go` のときだけ） |
| `examples/` | 架空の見本記事 |
| `drafts/` | 書いた記事を置く場所 |
| `research/` | 調査メモを置く場所 |
| `out/` | 道具が書き出すもの（Git に入れない） |

### scripts の一覧

| 道具 | すること | ネットにつなぐか |
|---|---|---|
| `wp_check.py` | WordPress につながるか・カテゴリとタグの ID | `--go` のときだけ（読むだけ） |
| `wp_draft.py` | Markdown を**下書き**で入れる・下書きの上書き・画像の送信 | `--go` のときだけ |
| `headings.py` | あなたが選んだ上位記事の URL から見出しを取り出す（10件まで・3秒おき・robots.txt を守る） | `--go` のときだけ |
| `review_check.py` | 推敲の機械チェック | つながない |
| `note_draft.py` | note に貼る形のファイルを作る | つながない |
| `gsc_auth.py` | Search Console の鍵を1回取る | `--go` のときだけ |
| `gsc_report.py` | Search Console の数字で振り返り | `--go` のときだけ（読むだけ） |

## できないこと（正直に）

- **公開・予約投稿はしません。** 道具は必ず「下書き」で入れます。公開はあなたが画面で押してください。公開済みの記事は上書きしません。
- **検索結果の自動取得はしません。** 検索エンジンの結果ページを機械で集めることは、多くの検索エンジンの規約で禁止されています。上位の URL は、エージェントのブラウザや検索の機能、またはあなたの目で確かめて `research/urls.txt` に書きます。
- **検索ボリュームの正確な数は出せません。** 目安が要るときは Google 広告の「キーワードプランナー」（Google 広告アカウントが必要）を人が使います。広告を出していないアカウントでは数字が幅で出ることがあります。
- **note には自動投稿しません。** note には一般に公開された投稿用 API が無いため、貼り付け用のファイルを作るところまでです。
- **順位を約束するものではありません。** 検索順位は検索エンジンが決めます。
- **法律の確認を代わりにするものではありません。** 推敲チェックは入口を拾うだけです。健康・美容・お金の記事など判断に迷うものは、専門家や各広告主・ASP の規定で確かめてください。
- WordPress.com の一部プランや、REST API を止めるプラグインを入れたサイトでは動かないことがあります。

## 困ったとき

- `401` が出る … ユーザー名とアプリケーションパスワードを確かめる。パスワードはプロフィール画面で作り直せます。
- `403 rest_cannot_create` … そのユーザーに投稿の権限がありません。
- `404` で `/wp-json/` が見つからない … 「設定 → パーマリンク」で一度「変更を保存」を押すと直ることがあります。
- それでも直らないときは、エージェントに `AGENT.md の「止まったとき」の手順で調べて` と頼んでください。

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。

## 困ったとき・もっと伸ばしたいとき

分からない・動かない・時間がかかっている——そんなときは、ひとりで抱えないでください。
**N-Hack の受講生ページ／個別コンサルチャンネル**から、担当にそのまま相談できます。
あなた専用のAIと伴走しながら、最短で結果まで一緒に持っていきます。

このキットのAIは、あなたが詰まったときや区切りのときに、自分から相談先を案内します。
