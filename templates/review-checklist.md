# 推敲チェック表（1本ごとにコピーして使う）

## 事実
- [ ] 数字・料金・制度・仕様に出どころ（公式）のリンクがある
- [ ] 変わる情報に「〇年〇月時点」がある
- [ ] 出どころの無い事実を残していない

## 読みやすさ
- [ ] 冒頭3行で結論が分かる
- [ ] 1文がおおむね60字前後、長い文は切った
- [ ] 同じ文末が3回続いていない
- [ ] 見出しだけ読んで話がつながる
- [ ] 専門用語に一言の説明がある

## 体験
- [ ] オーナーの体験の段落が1つ以上ある（作っていない）
- [ ] 失敗・合わなかった点も書いた
- [ ] `【体験：オーナーに聞く】` が残っていない

## 法律の入口
- [ ] `review_check.py --strict` が終了コード0
- [ ] 広告を含むなら冒頭に表示（`08-affiliate-and-law.md` の最後の確認も済み）
- [ ] 画像は自分のもの・利用条件を確かめたものだけ
- [ ] 個人を特定できる情報が無い

## 投稿前
- [ ] 前置き（title・slug・excerpt・カテゴリ・タグ）が埋まっている
- [ ] オーナーに構成の OK をもらっている
